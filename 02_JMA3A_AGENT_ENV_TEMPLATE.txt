JMA3A — AGENT ENVIRONMENT TEMPLATE
DO NOT COMMIT THE REAL VERSION OF THIS FILE
======================================================================

PURPOSE
-------
This is the PRIVATE environment contract for an autonomous coding/deployment
agent.

Recommended private filename:
.agent.env

The repository itself should contain a SAFE `.env.example` that excludes
deployment-agent credentials.

IMPORTANT SECURITY RULES
------------------------
1. NEVER commit .agent.env.
2. NEVER paste token values into README, issues, logs, screenshots, or chat.
3. NEVER expose GITHUB_TOKEN / VERCEL_TOKEN / SESSION_SECRET to browser code.
4. ONLY variables intentionally safe for the browser may use NEXT_PUBLIC_.
5. Prefer fine-grained GitHub credentials restricted to the target repository.
6. Rotate any token immediately if it is accidentally committed or publicly exposed.
